# Final Demo Video & Presentation Checklist

## Suggested 8–10 slides
1. Title, name, internship, project
2. Problem statement and objectives
3. Data sources and dataset overview
4. Cleaning and preparation
5. EDA and key visualizations
6. Time-series analysis and forecast evaluation
7. Customer segmentation and interpretation
8. Predictive modelling and verified evaluation metrics
9. Automated pipeline / dashboard demonstration
10. Conclusion, recommendations, limitations, thank you

## Demo recording sequence
1. Introduce the project and problem.
2. Show the repository structure.
3. Run the pipeline from VS Code terminal.
4. Open the generated report and charts.
5. Explain 2–3 verified insights.
6. Show the dashboard only if it actually runs or is deployed.
7. Close with limitations and next steps.

## Before submission
- [ ] Remove private data, tokens, API keys, and credentials
- [ ] Confirm commands work from a clean environment
- [ ] Check chart labels and report formatting
- [ ] Confirm metrics match saved outputs
- [ ] Check GitHub README and repository URL
- [ ] Keep the video concise and text readable
